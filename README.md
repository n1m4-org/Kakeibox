# Kakeibox

Android向けの家計簿アプリです。

## 画面構成
| タブ | 内容 |
|---|---|
| 明細 | 期間ごとの明細・収支、給料日カウントダウン、今日／今週／今月の予算、検索 |
| カレンダー | 日ごとの支出・収入、1日の予算を超えた日を赤で表示 |
| レポート | 月：カテゴリ内訳・前月比・支払い方法別・直近12か月の推移／年：年間の収支・月平均・月別推移・月別一覧 |
| 設定 | 予算・入力・期間・通知・データ・セキュリティ・表示 |

## 機能
### 記録
- **クイック入力**: ＋で下からシートが開き、金額→カテゴリのタップで今日の支出を記録（取り消し可、⌫長押しで全消去、支払い方法はチップで変更）
- **テンプレート**: よく使う記録をクイック入力の上部からワンタップで記録（金額を空欄にすると都度入力）。入力画面の右上から保存
- **定期の収支**: 家賃・サブスク・給料などを「毎月◯日（月末も可）」に自動で記録。アプリ表示時と1日1回のバックグラウンド処理で、過ぎた分もさかのぼって登録
- **カテゴリ**: 支出・収入それぞれに追加（名前・アイコン45種・色12色）、並べ替え、非表示。追加したカテゴリは編集・削除可（記録などで使われている場合は削除できず、非表示を案内）。「その他」は受け皿のため非表示不可
- **支払い方法**: 現金／クレジットカード／電子マネー／QRコード決済／銀行・口座振替／その他（既定値は設定で変更）
- **検索・絞り込み**: キーワード（メモ・カテゴリ・支払い方法）、種別、カテゴリ、支払い方法、金額範囲、期間

### 予算
- 「全体」と「支出カテゴリごと」に、**1日／1週間（月〜日）／1か月**の予算を設定
- 1日の予算は固定額＋繰り越し方式：今日の予算 = 1日の予算 ＋ 前日までの「1日の予算 − その日の支出」の合計（月の開始日、または金額を変更した日から数え直し）
- 1日の予算から今月の予算（1日の予算 × 期間の日数）を表示
- **日替わり**: 端末の時刻で 0:00 に「今日」が切り替わり、前日までの余り・超過が繰り越される。アプリを開いたままでも 0:00 に表示が更新され、端末の日付・タイムゾーン変更にも追従。ウィジェットは 0:00 過ぎに描き直す（端末の省電力機能により数分〜十数分遅れることがあります）
- **月の開始日（締め日）**: 1〜28日。例：25日にすると「25日〜翌月24日」を1か月として集計
- **給料日カウントダウン**: 給料日（土日なら前の金曜にも対応）まであと何日か、1日あたり使える金額（月予算の残り、未設定なら今月の収入の残り ÷ 残り日数）

### 通知
- **入力リマインダー**: 毎日指定の時刻に、その日の記録がなければ通知（通知からクイック入力）
- **使いすぎ通知**: 1日・週・月の予算（全体／カテゴリ）の80%・100%を超えたら通知（同じ期間・閾値は1回だけ）

### ホーム画面ウィジェット
- **支出クイック入力**: 今月の支出合計と「＋ 支出を追加」
- **今日の予算**: 置くときに「全体」またはカテゴリを選択（複数配置可）。サイズで表示が変わる
  - 2×2・2×3（正方形〜縦長）: ドーナツ型の円グラフ。輪は使った割合（80%超で黄、超過で赤）、中に残り / 今日の予算
  - 横1段: 残り / 今日の予算と細いバー。4マス幅以上はアイコンを左端、金額を右寄せ
  - 3×2・4×2 など横長: 名前・残り / 今日の予算・バー
- **支出の内訳**: 今月のカテゴリ別支出の上位5件

### データ・セキュリティ・表示
- **CSV書き出し／取り込み**: `日付,種別,カテゴリ,金額,支払い方法,メモ` 形式（UTF-8 BOM付き。取り込みは Shift_JIS にも対応）
- **バックアップ／復元**: 明細・テンプレート・定期の収支・予算・設定を1つのJSONファイルに
- **アプリロック**: 起動時と1分以上たってから戻ったときに、指紋・顔認証または端末のPINで解除
- **テーマ**: 端末に合わせる／ライト／ダーク
- **背景とアクリル効果**: 背景に好きな画像（または壁紙の色のグラデーション）を設定し、ぼかし・明るさを調整。カードやパネルは背景を透かすアクリル（すりガラス＋ノイズ＋光の縁）。※背景画像はバックアップに含まれません
- **配色**: Android 12以降は壁紙の色（Material You）に合わせる。背景の既定のグラデーションもその色から作る。収入は緑、支出は赤
- カテゴリは線画（Material Outlined）アイコンで表示。データは端末内（Room / SQLite）に保存

## 技術構成
| 項目 | 内容 |
|---|---|
| 言語 | Kotlin 2.0 |
| UI | Jetpack Compose (Material 3) |
| DB | Room（v4、AutoMigration でデータを保持したまま更新） |
| バックグラウンド処理 | WorkManager（定期の収支、リマインダー） |
| 画面遷移 | Navigation Compose |
| ウィジェット | Jetpack Glance |
| 認証 | androidx.biometric |
| 対応OS | Android 8.0 (API 26) 以上 |

```
app/src/main/java/com/kakeibox/
├── MainActivity.kt          タブ・画面遷移・クイック入力シート・アプリロック
├── QuickAddActivity.kt      ウィジェット・通知から開くクイック入力（透明Activity）
├── KakeiboxApplication.kt   通知チャンネル・定期処理の登録
├── AppGraph.kt              Repository・設定の生成（変更時にウィジェット更新・使いすぎ判定）
├── data/                    Entity・DAO・DB、期間・予算・集計・検索・CSV・バックアップなどのロジック
├── notify/                  通知（リマインダー・使いすぎ通知）
├── security/                アプリロック
├── widget/                  ホーム画面ウィジェット（3種）
└── ui/
    ├── MainViewModel.kt     表示中の期間・明細・集計・予算を StateFlow で提供
    ├── quickadd/            クイック入力（キーパッド・カテゴリ・テンプレート）
    ├── screens/             各画面
    └── components/          共通部品（グラフ・予算バー・選択チップなど）
```

計算ロジック（期間・繰り越し・定期の記録日・給料日・通知判定・検索・CSV・バックアップなど）は `data/` の純粋な関数にまとめ、`app/src/test/` に単体テストがあります。

## 配布とアプリ内更新
- 開発ブランチに push すると GitHub Actions（`.github/workflows/release.yml`）がテスト → 本番用の鍵で署名した APK をビルドし、
  GitHub Releases に `v1.0.<番号>`（APK は `kakeibox-<versionCode>.apk`）として公開します
- アプリは起動時（1日1回）と「設定 > アプリ > アップデートを確認」で最新版を確認し、［更新］でダウンロード → Android の更新画面を開きます
- 署名鍵は GitHub の Secrets（`KEYSTORE_BASE64`・`KEYSTORE_PASSWORD`・`KEY_ALIAS`・`KEY_PASSWORD`）に登録します。鍵ファイルはリポジトリに入れないでください

## ビルド
Android Studio でプロジェクトを開いて実行するか、コマンドラインで以下を実行します。

```sh
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 単体テスト
```
